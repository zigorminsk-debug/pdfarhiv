# 📦 PDF Compressor — архиватор PDF для Windows

> 🆕 **Версия 2.0** — теперь есть **объединение** и **разделение** PDF. Доступны 3 реализации с графическим интерфейсом (GUI):
> 1. **Python (`pdf_compressor.py`)** — описана ниже (`PDF_Compressor.exe`)
> 2. **C# / .NET 8 (`csharp/`)** — WinForms со встроенным Ghostscript (`PdfToolkit.exe`, см. `csharp/README.md`)
> 3. **Go (`go/`)** — нативный Win32 GUI со встроенным Ghostscript (`PdfToolkit_Go.exe`, см. `go/README.md`)

Приложение с графическим интерфейсом для сжатия PDF файлов **в 2 и более раза**. Работает через **Ghostscript** — стандарт индустрии для обработки PDF.

> ✅ Протестировано на реальных файлах: 1.9 МБ → 573 КБ (**x3.5**) и 1.9 МБ → 227 КБ (**x8.8**)

---

## 🚀 Быстрый старт (3 шага)

### 1. Установите Ghostscript
Скачайте **`gsXXXXw64.exe`** (AGPL Release, 64-bit) с официального сайта:
👉 **https://ghostscript.com/releases/gsdnld.html**

Установите в папку по умолчанию. Программа найдёт его автоматически.

### 2. Запустите архиватор
```bash
python pdf_compressor.py
```
*(или готовый `PDF_Compressor.exe`, если собрали через `build.bat`)*

### 3. Перетащите PDF → выберите цель → «СТАРТ СЖАТИЯ»
Результат появится рядом с оригиналом с суффиксом `_compressed`.

---

## ⚡ Главная фишка — режим АВТО

Выбираете **«⚡ АВТО — минимум 2x»** (стоит по умолчанию) и цель, например `2x` — программа сама перебирает профили от мягкого к агрессивному, пока файл не уменьшится в 2 раза:

```
🎯 Цель: ≤ 998.3 КБ (сжатие ≥ x2)
⚙ Пробую профиль «👁 Качество (300 DPI)»...     → 2.0 МБ (x1.0) — мало
⚙ Пробую профиль «📄 Баланс (150 DPI)»...       → 573 КБ (x3.5)  ✔ ЦЕЛЬ ДОСТИГНУТА
```

Это гарантирует, что цель будет достигнута **с максимально возможным качеством** — программа не станет сразу ужимать в кашу, если хватит мягких настроек.

## 📊 Профили сжатия

| Профиль | DPI | JPEG | Факт. сжатие* | Для чего |
|---------|-----|------|---------------|----------|
| ⚡ **АВТО — минимум 2x** | авто | авто | **x2 … x10** | Рекомендую: цель + лучшее качество |
| 🔥 **Максимальное** | 72 | 30% | **x8.8** | Архив, email, веб |
| 📄 **Баланс** | 150 | 60% | **x3.5** | Документы, отчёты |
| 👁 **Качество** | 300 | 85% | x1.0–2.0 | Печать, презентации |
| 📱 **Только текст** | 150 | 40% | **x3.2** | Сканы без фотографий |

\* замерено на тестовом 5-страничном скане 1.9 МБ (300 DPI со «шумом» и текстом)

## 🖥 Возможности

- **Drag & Drop** — перетаскивайте файлы прямо в окно
- **Цель в разах** — `1.5x / 2x / 3x / 5x / 10x` (для режима АВТО)
- **Батч-обработка** — десятки файлов за один прогон
- **Добавить папку** — рекурсивно заберёт все PDF из папки
- **Прогресс-бар + подробный лог** — видно, что происходит
- **Выбор папки назначения** — или сохранение рядом с оригиналом
- **Кнопка СТОП** — прервать обработку в любой момент
- **Умная защита** — если сжать не удалось, бесполезный файл удаляется, оригинал не портится
- **Проверка Ghostscript** — статус в шапке + кнопка «Указать вручную»
- Нормально работает с **кириллицей** в путях

## 🛠 Сборка в .exe (один файл, без Python на целевой машине)

На Windows запустите:
```bat
build.bat
```

Скрипт сам:
1. проверит Python и установит `pyinstaller`, `tkinterdnd2`, `pillow`
2. сгенерирует иконку
3. соберёт `dist\PDF_Compressor.exe` (~15 МБ)

Вручную:
```bat
pip install pyinstaller tkinterdnd2 pillow
python build_exe.py
```

> На целевом компьютере всё равно нужен **Ghostscript** — он и есть движок сжатия.

## 🔧 Что именно делает Ghostscript

```bash
gswin64c.exe -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 \
  -dColorImageResolution=150 -dGrayImageResolution=150 \
  -dColorImageDownsampleType=/Bicubic \
  -dJPEGQ=60 -dDownsampleColorImages=true \
  -dDetectDuplicateImages=true -dCompressFonts=true -dSubsetFonts=true \
  -sOutputFile=output.pdf input.pdf
```

| Параметр | Эффект |
|----------|--------|
| `Downsample` + `Resolution` | Уменьшает разрешение картинок до N DPI |
| `JPEGQ` | Перекодирует изображения в JPEG с заданным качеством |
| `DetectDuplicateImages` | Удаляет повторяющиеся картинки (частая проблема сканов) |
| `CompressFonts` / `SubsetFonts` | Оптимизирует шрифты, оставляет только используемые глифы |
| `CompatibilityLevel 1.4` | Совместимость со всеми просмотрщиками |

## ❓ Частые проблемы

| Проблема | Решение |
|----------|---------|
| «Ghostscript не найден» | Установите GS или нажмите «🔍 Указать вручную» → выберите `gswin64c.exe` |
| Файл не сжимается | В PDF нет изображений (только вектор/текст) — там нечего сжимать |
| Цель недостижима | PDF уже оптимизирован; программа применит лучшее из возможного |
| "Permission denied" | Закройте PDF в Adobe Reader / браузере перед сжатием |
| Долго на большом файле | Таймаут 5 мин на файл; для 500+ МБ выбирайте мягкий профиль |
