# PDF Toolkit 2.0 — Go (Нативный Win32 GUI)

Версия на языке **Go** без внешних зависимостей (не требует ни Python, ни .NET Runtime).
Компилируется в один автономный `.exe` файл (`PdfToolkit_Go.exe`), использующий нативный **Win32 API** (`user32.dll`, `comctl32.dll`, `comdlg32.dll`, `shell32.dll`) и встроенный **Ghostscript 10.05.1**.

---

## Преимущества Go-версии

- **Нативный Win32 интерфейс** — мгновенный запуск (< 10 мс), минимальное потребление оперативной памяти (~8 МБ RAM), стандартные системные диалоги и вкладки Windows 10/11.
- **Один автономный `.exe` файл (~25 МБ)** — втрое компактнее self-contained `.NET`-сборки (88 МБ), при этом **Ghostscript 10.05.1 уже встроен внутрь** и автоматически распаковывается при первом запуске в `%LOCALAPPDATA%\PdfToolkit\gs-10.05.1`.
- **Нулевые внешние зависимости в Go** — использует только стандартную библиотеку Go (`CGO_ENABLED=0`).

## Возможности (3 вкладки)

1. **🗜 Сжать**
   - Drag & Drop PDF-файлов и папок прямо в окно программы.
   - 5 профилей сжатия:
     - `⚡ АВТО — минимум 2x (рекомендую)` — перебирает профили от мягкого к агрессивному до достижения целевого коэффициента (`1.5x / 2.0x / 3.0x / 5.0x / 10.0x`).
     - `🔥 Максимальное (72 DPI, JPEG 30%)`
     - `📄 Баланс (150 DPI, JPEG 60%)`
     - `👁 Качество (300 DPI, JPEG 85%)`
     - `📱 Только текст (150 DPI, JPEG 40%, Subsample)`
   - Выбор папки сохранения или сохранение рядом с оригиналом (`_compressed.pdf`).
2. **🔗 Объединить**
   - Объединение нескольких PDF в один в заданном порядке (кнопки `⬆ Вверх` / `⬇ Вниз`).
   - Без перекодирования изображений (`PassThroughJPEGImages=true`).
3. **✂ Разделить**
   - Каждая страница в отдельный PDF / порциями по N страниц / по диапазонам (`1-3,5,7-10`).
   - Сохранение в подпапку `<имя>_pages` без потери качества.

### Горячие клавиши
- `Ctrl+O` — добавить PDF-файлы в текущую вкладку
- `Delete` — удалить выбранные файлы из списка
- `F5` — запустить операцию текущей вкладки
- `Esc` — остановить текущую операцию

## Сборка из исходников

На Windows запустите:
```bat
cd go
build.bat
```

Или вручную:
```powershell
cd go
Copy-Item ..\csharp\PdfToolkit\Bundle\gs10051-win64.zip internal\core\bundle\gs.zip
go test -v ./internal/core/...
go build -trimpath -ldflags="-s -w -H=windowsgui" -o dist\PdfToolkit_Go.exe ./cmd/pdftoolkit
```
