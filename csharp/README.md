# PDF Toolkit 2.0 — C# (.NET 8, WinForms)

Версия без Python. Одним `.exe` файлом: сжатие, объединение и разделение PDF.
Внутри — тот же подход, что в Python-версии: обёртка над **Ghostscript** (готовый движок, без собственного PDF-кодека).

## Запуск (готовый exe)

Просто запустите `dist\PdfToolkit.exe`. Ничего устанавливать не нужно:

- **Ghostscript 10.05.1 встроен** в exe. При первом запуске он распаковывается в `%LOCALAPPDATA%\PdfToolkit\gs-10.05.1` (несколько секунд, права администратора не нужны).
- **Microsoft Visual C++ Redistributable** нужен Ghostscript. Если его нет в системе (это бывает на чистой Windows), программа предложит установить его. Установщик скачивается с официального `aka.ms` и запускается с запросом UAC.
- .NET встроен в exe, отдельно ставить его не нужно.

Если на ПК уже установлен Ghostscript, программа может использовать и его, но по умолчанию используется встроенный. Путь можно указать вручную кнопкой **«Указать вручную»**.

## Что нужно для сборки из исходников

| Что | Где взять |
|---|---|
| .NET 8 **SDK** | https://dotnet.microsoft.com/download/dotnet/8.0 |
| Встроенный Ghostscript | уже лежит в `PdfToolkit\Bundle\gs10051-win64.zip` (состав и лицензия AGPL — в `Bundle\README.txt`) |

## Сборка

Дважды щёлкните `build.bat` (или запустите из командной строки). Скрипт:
1. проверяет наличие .NET SDK;
2. запускает тесты ядра (нужен Ghostscript; пропустить: `set SKIP_TESTS=1`);
3. собирает **один** `dist\PdfToolkit.exe` (self-contained, ~65 МБ — .NET внутри, ставить .NET не нужно).

Ручная сборка: `dotnet publish PdfToolkit\PdfToolkit.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`

## Вкладки

- **🗜 Сжать** — список PDF (перетаскивание, папка), профиль и цель (1.5 / 2 / 3 / 5 / 10 ×).
  Профиль **⚡ АВТО** перебирает варианты от мягкого к агрессивному и берёт первый, который даёт нужную цель.
  Если цель недостижима, сохраняется лучший из возможных результат. Оригинал не трогается никогда.
- **🔗 Объединить** — несколько PDF в один. Порядок меняется кнопками ⬆ ⬇. Изображения **не перекодируются**, качество полностью сохраняется.
- **✂ Разделить** — каждая страница отдельно / порциями по N / по диапазонам (`1-3,5,7-10`).
  Результат в подпапке `<имя>_pages`. Качество тоже не теряется.

Горячие клавиши: `Ctrl+O` — добавить файлы, `F5` — запуск текущей вкладки, `Esc` — остановить операцию.

## Ограничения (честно)

- **Ровно 2× не гарантируется для любого файла.** Сжатие идёт за счёт изображений (даунсэмплинг, JPEG, дубликаты, шрифты).
  Текстовый PDF без картинок так не уменьшить вдвое. Для скан-документов типичный результат — 3–15×.
- Профили «Баланс», «Качество» и «Только текст» не сжимают изображения, если их DPI близок к целевому (порог даунсэмплинга Ghostscript — 1.5×). Для 2× нужен АВТО или «Максимальное».
- Объединение и разделение не уменьшают размер — это прямые операции без перекодирования.

## Тесты

`tests\CoreTests\run_tests.bat` — 25 проверок на **реальном Ghostscript**: разбор диапазонов, подсчёт страниц,
объединение, извлечение, все профили, АВТО-режим с целью 2×, битый файл, отмена.
Тестовые PDF генерируются самим Ghostscript (растровые изображения 1500×2000, как у скана).

## Структура

```
csharp/
├── build.bat                     сборка одного exe (тесты + publish)
├── dist/PdfToolkit.exe           готовый exe, 88 МБ, Ghostscript внутри (собран кросс-компиляцией на Linux)
├── PdfToolkit/
│   ├── PdfToolkit.csproj
│   ├── Program.cs
│   ├── Core/                     логика без UI (тестируется отдельно)
│   │   ├── GhostscriptService.cs   запуск gs, профили, АВТО-режим, merge/extract
│   │   ├── GsBundle.cs             распаковка встроенного gs, установка VC++
│   │   └── PageRanges.cs           разбор «1-3,5,7-», нарезка
│   └── UI/
│       ├── MainForm.cs             три вкладки, фоновые операции, лог
│       └── FileListPanel.cs        список файлов, drag&drop, сортировка
├── PdfToolkit/Bundle/            встроенный gs10051-win64.zip + README.txt
└── tests/CoreTests/              тесты ядра (тот же код Core/)
```

## Статус проверки

- ✅ Ядро проверено на Linux с реальным Ghostscript 10.05: 25/25 тестов.
- ✅ Проект компилируется без ошибок и предупреждений (.NET 8 SDK). `dist\PdfToolkit.exe` собран (88 МБ), в нём проверено наличие архива Ghostscript.
- ⚠️ **exe не запускался на Windows** — в среде разработки нет Windows и дисплея. Окно, drag&drop, распаковка Ghostscript и установка VC++ не проверены на реальной машине. Перед передачей запустите exe на Windows и выполните: сжатие одного PDF, объединение двух файлов, разделение на страницы.
